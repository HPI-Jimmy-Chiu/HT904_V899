# 強制機制層入門

## 一句話理解

| 工具 | 白話比喻 | 主要用途 |
|------|---------|---------|
| Hook | 門口警衛 | 在 AI 動手前後即時攔截或提醒 |
| Script | 固定工法機器 | 把重複、脆弱、需要一致性的檢查寫成可執行程式 |
| CI | 大樓總閘門 | 在提交、合併、發版前做團隊級的最後把關 |
| Checklist | 飛機起飛前清單 | 讓人和 AI 都不漏掉該確認的項目 |

## HT9045 適用建議

| 機制 | 建議 | 原因 |
|------|------|------|
| Hook + Script | **優先採用** | 寫入邊界保護（多版本共存，唯讀/可寫劃分明確） |
| Checklist | **優先採用** | 安全變更審查（運動控制/IO/互鎖/溫控修改頻繁） |
| CI | 暫緩 | HT9045 使用 SVN + BCB6，CI 整合成本較高 |

## Hook 最適合做什麼

- 寫入範圍保護（舊版目錄唯讀、設定檔需備份）
- 禁止修改驅動定義檔（AGENTS.md 禁改清單中的 .h 檔）
- 自動提示安全規則

## Script 最適合做什麼

- 路徑白名單檢查（check-write-boundary.ps1）
- 設定檔備份提醒（.ini, .csv, .dat, .db）
- 版本目錄讀寫權限判斷

## Checklist 最適合做什麼

- 安全變更審查（修改馬達/氣缸/互鎖/溫控前後）
- 每週治理巡檢
