## 第一週最低交付

1. 讓 AI 有明確寫入白名單
2. 讓日誌開始持續累積
3. 讓至少一條安全審查流程落地
4. 讓新知識有 Skill 或 ADR 可沉澱

## 啟動風險

| 風險 | 對策 |
|------|------|
| 邊界不清楚 | 先做白名單與唯讀目錄 |
| 共享設定誤改 | 先定義備份規則 |
| 經驗流失 | 第一天就啟用 Daily Worklog |
| 治理成本太高 | 先裝最小 Pack，不一次全開 |
