# Safety Change Review Checklist

## 變更前

- [ ] 已確認這次是否屬於運動、IO、互鎖、模式切換、警報或共享設定變更
- [ ] 已確認檔案在可寫白名單內
- [ ] 若涉及設定檔，已完成備份
- [ ] 已定義 rollback 方案
- [ ] 已列出受影響模組與流程

## 變更中

- [ ] 只做最小必要修改
- [ ] 沒有順手改 unrelated 區域
- [ ] 驗證方法在實作前已定義
- [ ] 重要假設已記錄

## 變更後

- [ ] 已更新 Daily Worklog
- [ ] 必要時已新增 ADR
- [ ] 若安全規則改變，已同步更新 Hook / Script / Policy / Instruction
- [ ] 已確認無邊界漂移或例外放寬未記錄

## 結論

- [ ] 可進入下一步驗證
- [ ] 需要更高層級審查
- [ ] 必須先回退
