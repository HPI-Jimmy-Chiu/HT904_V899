# Weekly Maintenance Review Checklist

## Skills

- [ ] 是否有新流程尚未建立 Skill
- [ ] description 是否仍含足夠觸發詞
- [ ] 是否有 Skill 長期未驗證
- [ ] 是否有 Skill 已經過胖需要拆分

## Prompts

- [ ] 是否仍符合實際工作流
- [ ] 是否有一個 Prompt 同時做太多事
- [ ] 是否需要新增或淘汰 Prompt

## Instructions

- [ ] applyTo 是否過寬
- [ ] 是否有多個關注點被塞進同一檔案
- [ ] 是否與 L0 或 README 重複

## Hooks / Scripts

- [ ] Hook 是否仍需要，沒有造成誤攔截
- [ ] Script 是否仍能單獨執行
- [ ] Policy 檔是否反映目前的白名單與唯讀區

## 記憶與日誌

- [ ] Daily Worklog 是否持續更新
- [ ] Weekly Review 是否持續更新
- [ ] ACTIVE 或其他追蹤檔是否仍可信

## 行動

- [ ] 本週需立即處理的項目已列清單
- [ ] 下週優先順序已決定
