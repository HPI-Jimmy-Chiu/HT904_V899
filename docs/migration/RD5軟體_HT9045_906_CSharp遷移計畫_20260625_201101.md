## 1. 目標架構（ports-and-adapters / 六角）

```
        ┌─────────────────────────────────────────────────────────┐
        │ HT9045.App（組合根 / DI）— 唯一決定 Sim↔Real、Stub↔WinForms │
        └───────────────┬─────────────────────────┬───────────────┘
                        │                         │
        ┌───────────────▼──────────┐   ┌──────────▼──────────────┐
        │ HT9045.Core（編排/狀態機）│   │ Presentation.Abstraction │

   │HardwareAbstr. │  │   (events)        │  │Views.Stub  │   │ UI.WinForms  │
   │ 硬體 ports    │  │ConfigChanged等    │  │(開發/測試) │   │(之後接顯示)  │

  ┌────▼──┐ ┌──▼──────────┐
  │ .Sim  │ │ .Native     │   →  HwInterop.dll(C-ABI) → 既有 C++ wrapper → 驅動
```

## 3. 硬體 Ports（介面目錄 + 雙轉接）

| Port | 由 C++ 接縫對應 | 關鍵方法（保留名） | Sim（現在） | Real（之後） |
|------|----------------|-------------------|-------------|--------------|
| `IMotorPort` | `HTMotor`(Motor/HTMotor.h:31，~50 virtual) | InitMotor/MoveToPos/ReadPos/HomeObject/HomeFlag/Stop/MotionDone/GetAlarm/SetSpeed/ServerOnOff/SetSoftLimit/JogP/JogN/ScanMotorStatus | SimMotor：回成功＋假位置，MotionDone=true | P/Invoke→HwInterop→TMySMCMotor/TMyGALILMotor |
| `IIoPort` | `TLaneIO`(MyLaneIo.h) | IOBitOn/IOBitOff/IOByteOut/IOOutBitStatus/IOInputBit/IOInputByte（int 回傳<0=fail） | SimIoBackend：記憶體位元圖 | →HwInterop→mn_set/get_port_bit(MN200) |
| `IKeyProPort` | `KEYPRO_GET_LEVEL`(HS_Function.cpp:4933) | int GetLevel(uint) | StubKeyPro：回 1（過 SECS gate） | LoadLibrary/GetProcAddress shim（只解析此函式，去 std::string） |
| `ITesterInterface` | 906 §9.2 dispatch | Find/RunTestProgram/SendMSG_CMD/CloseGpibProgram/GetTesterResult | SimTester：把現有 OFF_LINE `SimulateBin()`(TesterTCP.cpp:249-267/554) 升級成類別 | GPIB 橋維持 32-bit 外部程序(WM_COPYDATA)，RS232/TCP 走純 C# |
| `ITempControlPort` | Delta DTK4848(serial) | 讀值/設定點 | SimTempControl | 純 C# 序列 |

**Marshalling 規範（接縫盤點 §A）**：結構一律 `[StructLayout(LayoutKind.Sequential)]`＋對齊單元測試（如 MN200 `SPEED_PAR`）；`HANDLEDMC`→`IntPtr`＋生命週期；陣列 `Marshal.AllocHGlobal`＋明確釋放；**KeyPro/SECS 用 `char*`+length，禁 `std::string` 跨界**。
**跨位元地雷**：GPIB 橋走 WM_COPYDATA 給 32-bit 程序，`MessageDef.h` 的 `MV`/`VM` 內嵌 `HWND`(行 259-260)指標寬度會錯位→改 `DWORD`+`HandleToLong` 或移出；扁平 `M_V`(InterfaceSYS.h:222) 才安全。

## 6. 基礎建設與橫切

1. **SQLite**：`Microsoft.Data.Sqlite`（原生 C#，非 interop），`IHandlerDb` 包住 cMyDB 的 get_table「字串格」模式。
2. **Big5↔UTF-16**：單一邊界 helper（`Encoding.GetEncoding(950)`；.NET 8 需 `RegisterProvider`）；內部一律 UTF-16；單元測試含 U+FFFD 亂碼斷言。
3. **Config 載入**：嚴格比對 cinitial.cpp 欄位順序（Gerneral.ini/Mot_Table.csv/IO_Table.csv）。
4. **Logging**：對應 handlerlog/ARMSLog。
5. **Golden baseline / 特徵化測試**：回放實機 log（Task_ListWithTime/EventLog/State Record/TCP/SECS/GPIB），diff C# vs C++。config 解析 byte-exact；時間序列允許 .zzz 毫秒/浮點字串容差。
6. **執行緒模型**：即時留 native；C# 編排用 async/Task 或單一編排執行緒；native→C# callback 安全 marshal 回 C# 端。
7. **組合根/DI**：Pure-DI（手寫 CompositionRoot），config 旗標 `HW=Sim|Real`、`UI=Stub|WinForms`；預設開發＝Sim+Stub（無硬體/native DLL），生產＝Native+WinForms。

## 9. 不做什麼
(1) 不整檔自動轉譯。(2) 不在 C# 重寫運動/低階 IO/互鎖/安全/ATC 即時（保留 native）。(3) 不改 906 C++ 樹與 AGENTS.md 禁改驅動標頭。(4) **離線 Sim+Stub 迴圈未綠前不接實體硬體或真 WinForms**。(5) 不讓 std::string/VCL 型別/指標寬 HWND 跨 C-ABI。(6) 一次只搬一個狀態機，且必上機回歸。(7) 不整包搬全域結構。(8) SQLite 不走 interop。(9) 不直接 commit main；不擅自擴大到他客戶硬體。
