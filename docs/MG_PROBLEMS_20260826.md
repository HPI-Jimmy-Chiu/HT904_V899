## B. 方法論邊界（告知，不需你回覆）

- 矩陣的「MISSING≠功能一定缺」：公司可能改寫過等價實作。位元組簽章未命中的叢集，
  波次內仍會先確認 V910 現狀再搬（這是 C 類判定的第二關）。
- 註解粒度 ≠ 變更粒度：一則區塊註解下可能有數十行變更；工作量以 hunk 為準，
  337 是註解粒度的計數。
- V899 有少量**無 //AI 註解的手改**可能存在；Phase 3 收尾會用
  `git diff bb69c60..b515ed5` 全量對帳補漏，不只靠註解矩陣。
